# Registro de decisiones de VitaDAW

Las decisiones de arquitectura que afectan al comportamiento del DAW se
registran aquí para que su fundamento no dependa de conversaciones externas.

Formato breve para cada decisión:

- **Fecha:** de adopción, si consta; en caso contrario, fecha de registro.
- **Estado:** vigente, pendiente de implementar o sustituida.
- **Decisión:** qué política o solución se adoptó.
- **Motivo y evidencias:** qué riesgo o necesidad resuelve y dónde se comprobó.

No atribuir retrospectivamente una fecha de adopción sin evidencia. Si una
decisión cambia, crear un registro nuevo o anotar su sustitución sin borrar
el razonamiento anterior.
